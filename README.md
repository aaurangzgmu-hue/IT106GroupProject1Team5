For our program we built a schedule and event tracker. Our program will ask for an input of the amount of events a student plans to attend. There is a max of three events and a minimum of one event for the tracker to run. With that in mind the program will tell the student to enter the number of events and then it will check to make sure the student entered a valid input and if they don’t it will prompt them to add a different input until they enter a valid input. We did this with a simple if else statement. After catching a valid input the program will proceed to prompt the user to enter the distance between the events. We decided to set up an array to store the inputs. With that information our program will be able to calculate the total travel time and the calories burned. Next our program will get the event length from the user. It also has the restrictions applied to ensure the user inputs a valid number. We also used if else statements for the set up of the event length section. Finally, we took all the amounts that the user imputed and began the calculations required. This could be to find the total event time, total travel time, total calories burned, and total free time remaining if we consider the student having sixteen hour days. 
There were a few revisions to the code after the meeting with the professor. We removed the array and used if else statements instead. We also implemented the use of the J option pane for all of the user inputs and outputs.
